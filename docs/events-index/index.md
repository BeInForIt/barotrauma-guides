# Указатель событий

Страница в работе.

Здесь будет одна таблица со всеми событиями игры по алфавиту: идентификатор,
имя по-русски и по-английски, файл-источник, пакет (игра или мод) и ссылка на
разбор. Таблица собирается машинно из файлов игры, поэтому новое событие
попадает в неё строкой, а не переписыванием страницы.
